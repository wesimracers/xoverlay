# OverlayApp for Windows x64

Download `OverlayApp.exe` and run it normally. Python, Qt, the ordinary guard, the administrative setup helper and factory configuration are embedded in this single file. Windows PowerShell and .NET are existing Windows components used by optional protection features. The program creates personal settings locally on first use; no personal configuration is included.

See the repository README, `THIRD_PARTY_NOTICES.md` and `licenses/` for build/use documentation and the bundled component license texts. `SHA256SUMS.txt` identifies these artifacts. `verification.json` records static inspection of 39 current source modules and embedded helper resources without launching the application or setup. Experimental elevation behavior retains the limitations described in the source documentation.
