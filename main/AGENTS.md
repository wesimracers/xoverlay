# Source and interface language

All user-visible interface text, status messages, errors, installer/helper output, and new code comments or documentation strings must be in English only.

Preserve existing persisted keys, protocol fields, identifiers, filenames used for recovery, and user data for compatibility. Translate display labels without renaming stored settings or journal files. Proper names and external data retain their original spelling.

Before shipping interface changes, audit the changed Python and protection helper sources for Portuguese text and verify the rendered interface.
